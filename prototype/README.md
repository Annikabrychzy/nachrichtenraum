# Unendlicher Feed

Ein statischer, GitHub-tauglicher Web-Prototyp für einen VR-Nachrichtenraum. Die Szene vermittelt politische Informationsüberflutung: Meldungen erscheinen zunächst langsam und anschließend immer schneller, lassen sich öffnen, aber beim Schließen entstehen weitere.

## Start

`index.html` direkt im Browser öffnen oder über GitHub Pages veröffentlichen.

## Auf GitHub veröffentlichen

1. Ein neues, leeres Repository bei GitHub anlegen.
2. Diese Dateien in das Repository hochladen oder lokal committen und pushen.
3. Unter **Settings → Pages** als Quelle den Branch `main` und den Ordner `/(root)` auswählen.

Danach ist die Erfahrung über GitHub Pages erreichbar.
