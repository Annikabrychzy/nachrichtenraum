# Nachrichtenraum VR

Eine erste browserbasierte VR-Webseite für einen Nachrichtenraum.

## Starten

Öffne `index.html` in einem Browser. Im VR-Headset öffnest du die veröffentlichte Website und wählst **Enter VR**.

Die erste Version enthält:

- einen begehbaren 3D-Raum mit A-Frame/WebXR
- eine Nachrichtenwand
- ein Eingabefeld für neue Nachrichten
- Bedienung mit Desktop-Maus und kompatiblen VR-Headsets

> Nachrichten werden in dieser ersten Demo nur im aktuellen Browser angezeigt. Für einen echten Mehrnutzer-Chat ergänzen wir als nächsten Schritt einen Server bzw. eine Datenbank.
